Weather Skill

基于高德地图 MCP Server 的天气查询技能

Claude Code MCP Protocol 高德地图 API

📋 概述

本指南将帮助您创建一个名为 weather-skill 的 Claude Code 技能， 该技能通过调用高德地图的 MCP Server 来查询实时天气信息。Skills 是 Claude Code 的扩展能力， 允许您定义可重用的提示词和工作流程。

├── .claude/
│   ├── settings.json          # MCP Server 配置
│   └── skills/
│       └── weather-skill.md   # 技能定义文件
├── README.md
└── package.json               # (可选) 项目配置

🚀 详细开发步骤

1

获取高德地图 API Key

前往高德开放平台注册并创建应用

  1. 访问 https://lbs.amap.com/
  2. 注册/登录高德开放平台账号
  3. 进入控制台 → 应用管理 → 创建新应用
  4. 添加 Key，服务平台选择 "Web服务"
  5. 复制生成的 API Key
2

创建项目目录

初始化 weather-skill 项目结构

Terminal 
# 创建项目目录
mkdir -p weather-skill/.claude/skills
cd weather-skill

# 初始化项目 (可选)
npm init -y
3

配置 MCP Server

在 .claude/settings.json 中配置高德地图 MCP

.claude/settings.json 
{
  "mcpServers": {
    "amap-maps": {
      "command": "npx",
      "args": [
        "-y",
        "@amap/amap-maps-mcp-server"
      ],
      "env": {
        "AMAP_MAPS_API_KEY": "您的高德地图API_KEY"
      }
    }
  }
}

⚠️ 注意：请将 您的高德地图API_KEY 替换为您在步骤1中获取的实际 API Key。 建议使用环境变量来存储敏感信息。

# Weather Skill

## 触发词
- 查询天气
- 天气怎么样
- weather
- 今天天气

## 使用方法

当用户询问天气相关问题时，执行以下步骤：

1. **解析城市名称**
   - 从用户输入中提取城市名称
   - 如果未指定城市，询问用户想查询哪个城市的天气

2. **调用高德地图 MCP 工具**
   - 使用 `maps_weather` 工具查询天气
   - 参数：city（城市名称）

3. **格式化输出结果**
   - 城市名称
   - 当前天气状况
   - 温度（当前/最高/最低）
   - 风向和风力
   - 湿度
   - 空气质量（如有）

## 示例对话

**用户**: 北京今天天气怎么样？

**助手**: 让我为您查询北京的天气信息...

🌤️ **北京市天气**
- 天气：晴
- 温度：25°C
- 风向：东南风 2级
- 湿度：45%
- 空气质量：良

## 错误处理

- 如果城市名称无法识别，提示用户重新输入
- 如果 API 调用失败，显示友好的错误信息
- 建议用户检查网络连接或稍后重试

## 依赖

- 高德地图 MCP Server (`@amap/amap-maps-mcp-server`)
- 有效的高德地图 API Key

❓ 常见问题

Q: MCP Server 连接失败？

确保已安装 Node.js 和 npm，并检查 API Key 是否正确配置。

Q: 如何使用环境变量存储 API Key？

在 shell 配置文件中添加 export AMAP_MAPS_API_KEY="your_key"，然后在 settings.json 中使用 ${AMAP_MAPS_API_KEY}。

Q: 技能没有被识别？

确保 .md 文件位于 .claude/skills/ 目录下，并重启 Claude Code。
