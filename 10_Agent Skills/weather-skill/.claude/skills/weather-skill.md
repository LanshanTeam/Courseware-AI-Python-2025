# Weather Skill

## 触发词
- 查询天气
- 天气怎么样
- weather
- 今天天气

## 使用方法

当用户询问天气相关问题时，执行以下步骤：

1. **解析城市名称**
   - 从用户输入中提取城市名称
   - 如果未指定城市，询问用户想查询哪个城市的天气

2. **调用高德地图 MCP 工具**
   - 使用 `maps_weather` 工具查询天气
   - 参数：city（城市名称）

3. **格式化输出结果**
   - 城市名称
   - 当前天气状况
   - 温度（当前/最高/最低）
   - 风向和风力
   - 湿度
   - 空气质量（如有）

## 示例对话

**用户**: 北京今天天气怎么样？

**助手**: 让我为您查询北京的天气信息...

🌤️ **北京市天气**
- 天气：晴
- 温度：25°C
- 风向：东南风 2级
- 湿度：45%
- 空气质量：良

## 错误处理

- 如果城市名称无法识别，提示用户重新输入
- 如果 API 调用失败，显示友好的错误信息
- 建议用户检查网络连接或稍后重试

## 依赖

- 高德地图 MCP Server (`@amap/amap-maps-mcp-server`)
- 有效的高德地图 API Key
